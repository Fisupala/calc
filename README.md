# Private Result calc

A static, GitHub Pages-ready calc with a dark interface and a pay-to-unlock result state.

## Demo checkout

The checkout popup is intentionally local-only. It is clearly labeled as a demo, accepts dummy values, does not send requests, and does not store card data. Never enter real payment details into it.

This is not payment processing or payment verification. For real payments, use a hosted checkout provider or a server-side payment integration.

## Run locally

Open `index.html` directly in a browser, or serve the folder with any static server.

## Deploy to GitHub Pages

Push the repository to GitHub, then choose **Settings > Pages > Deploy from a branch** and select the branch containing these files and the root folder.
